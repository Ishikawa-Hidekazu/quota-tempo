# Support

Public-beta support covers installation defects, missing or damaged release artifacts, incorrect version or SHA-256 metadata, reproducible failures in documented acquisition paths, and security or privacy defects.

Contact: [h@ishikawa.co](mailto:h@ishikawa.co)

Include the QuotaTempo version, macOS version, provider application or CLI version, displayed source, freshness, source state, and the exact user-visible error. Do not send provider source files, raw responses, prompts, transcripts, credentials, tokens, cookies, private URLs, or personal quota values.

Support is asynchronous and best-effort during the public beta. It does not include provider account support, quota changes, workflow consulting, screen sharing, or a guaranteed response time.
